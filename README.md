# ⚡ Apex City 3D: Neon Horizon

## 🎮 Game Features

- **🌆 Complete Open-World Metropolis (6,400 × 6,400 px)**:
  - **Downtown Skyscrapers**: High-rise glass towers with lit windows, rooftop helipads, air conditioners, and flashing red aircraft beacons.
  - **Neon Entertainment Strip**: Vibrant nightlife district with glowing neon storefronts and signs.
  - **Central Park & Lake**: 3D procedural trees, walking paths, and lake with water ripples.
  - **Industrial Docks & Harbor**: Shipping container obstacle slaloms, oil storage silos, and warehouses.
  - **Outer Loop Expressway**: Multi-lane highway looping the city for high-speed top-speed runs.
  - **Dynamic Traffic Infrastructure**: Working traffic lights (Red/Green cycles), street lamp illumination, and speed cameras.

- **🏎️ Realistic 3D Vehicle Dynamics & Drifting**:
  - Longitudinal acceleration, aerodynamic drag, and caster steering return.
  - Dynamic power-drifting: break traction with the Handbrake (<kbd>SPACE</kbd>) to initiate tire smoke and build combo multipliers for bonus cash.
  - 4 independent spinning wheels with front steering pivot and suspension body roll/pitch.
  - Twin-exhaust Nitro Boost (<kbd>SHIFT</kbd>) with animated exhaust flame cones.
  - Stunt jump ramps to launch cars into the air.

- **🚓 Police Pursuits & Street Racing**:
  - Heat / Wanted Star System (1–5 Stars): Police interceptors chase and attempt PIT maneuvers with flashing sirens.
  - Street Race Circuits: Checkpoint-based multi-lap races against competitive AI rivals.
  - Express Delivery Missions: Timed cargo delivery rush across town.

- **🎥 Multi-View Dynamic 3D Camera (<kbd>C</kbd>)**:
  - **CHASE**: Third-person follow camera with speed FOV and drift lag.
  - **CLOSE**: Tight bumper view.
  - **HOOD**: High-speed first-person view.
  - **HELI**: Aerial helicopter tactical view.

- **🛠️ Apex Motors Garage & Upgrades**:
  - 6 unlockable vehicles: *Street Pulse (Hot Hatch), V8 Thunderbolt (Muscle), Fujiwara Drift (JDM Legend), Apex GT (Supercar), Metro Enforcer (Police Interceptor), Cyber Phantom (Hypercar)*.
  - Performance upgrades: Turbo Engine, Racing Tires, Stage-2 NOS, Reinforced Chassis.

- **🔊 100% Procedural Web Audio Engine**:
  - Dynamic RPM engine synthesis, drift squeal, collision crunches, sirens, and built-in synthwave cyber radio.

## 🚀 Quick Start

1. Clone this repository:
   ```bash
   git clone <REPO_URL>
   cd "game website"
   ```

2. Install dependencies (optional for local Three.js):
   ```bash
   npm install
   ```

3. Start the local server:
   ```bash
   npm start
   ```

4. Open your browser at:
   ```
   http://localhost:3000
   ```
